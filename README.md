# konnek open source

**konnek** connects the tools small and medium-sized businesses in Europe already use -- simple to
set up, hosted GDPR-compliant in Germany, with AI built in. Learn more at <https://konnek.de>.

This repository is the landing page of our open source space, published with GitHub Pages at
**<https://konnekde.github.io>**.

## Mission

While building konnek we create things that are useful beyond our own product. We share them here:

| Area | What |
|---|---|
| Integrations | Connectors and examples for linking your software -- especially European tools -- with konnek |
| Capabilities | Building blocks and interfaces that let other systems talk to konnek |
| Tools | Developer utilities we built for ourselves and found worth sharing |
| Skills | Reusable instructions and workflows for AI coding agents |

## Development

The site is a single static `index.html` (no build step; `.nojekyll` disables Jekyll).
Open it in a browser to preview; every push to `main` publishes it.
